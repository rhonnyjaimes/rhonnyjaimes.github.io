# Portafolio Profesional — Rhonny Andrés Jaimes González

Portafolio web interactivo y CV listo para imprimir en PDF de **Rhonny Andrés Jaimes González**, Ingeniero en Computación y Desarrollador Full Stack.

## Estructura del Proyecto

- `index.html` — Portafolio personal completo (Sobre mí, Habilidades, IA/Antigravity, Trayectoria, Proyectos de GitHub filtrables y Contacto).
- `cv.html` — Currículum Vitae actualizado, optimizado para 1 página y listo para exportar a PDF con un clic (`Imprimir / Guardar como PDF`).
- `styles.css` — Estilos modernos con modo oscuro/claro, glassmorphism y diseño 100% responsivo.
- `script.js` — Filtros de proyectos, cambio de tema, menú móvil, copiado rápido de correo y animaciones al hacer scroll.
- `assets/profile.jpg` — Fotografía profesional de perfil.

## Cómo verlo localmente

Abre `index.html` o `cv.html` directamente en tu navegador, o ejecuta un servidor local:

```bash
npx serve .
```

## Cómo publicarlo gratis en GitHub Pages

1. Sube esta carpeta a un repositorio en tu cuenta `github.com/rhonnyjaimes` (por ejemplo, `portafolio` o `rhonnyjaimes.github.io`).
2. Ve a **Settings → Pages → Source: Deploy from a branch (`main`)**.
3. En minutos tendrás tu portafolio en vivo para compartir en tu CV, LinkedIn y bio de GitHub.
